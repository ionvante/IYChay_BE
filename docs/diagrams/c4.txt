[Padre] ──(web/app móvil)────┐
[Profesor] ──(web)───────┐   │
[Director/Admin] ─(web)──┴──▶  Plataforma IYChay (MVP)
                                   │
                                   ├─ Notificaciones por email (post-MVP)

C4-3 · Componentes del Backend
Spring Boot API
├─ AuthComponent
│   ├─ /auth/login  (JWT)
│   └─ /auth/me     (perfil/rol)
│
├─ AulasComponent
│   ├─ /aulas [GET/POST]
│   └─ /aulas/{id} [GET/PUT/DELETE]
│
├─ AlumnosComponent
│   ├─ /alumnos [GET/POST]
│   ├─ /alumnos/{id} [GET/PUT/DELETE]
│   └─ /alumnos/{id}/ficha [GET]
│
├─ MensajesComponent (MVP simple REST)
│   ├─ /mensajes [GET/POST]
│   └─ /conversaciones [GET]
│
└─ ReportesIAComponent
    ├─ /reportes [GET] (listar)
    ├─ /reportes/{id} [GET] (detalle)
    ├─ /reportes/generar  [POST]  ← llama a Microservicio IA
    └─ /reportes/{id}/pdf [GET]   ← descarga

Microservicio IA (FastAPI/Java ligero):

POST /ia/generar body: { scope: "alumno|aula|colegio", id, periodo, pesos: {asistencia, notas} }

Respuesta: { texto, metricas, html, pdf_url? }

Despliegue & CI/CD (resumen)
- Ramas: main (prod), develop (stage), feat/*.
- Pipelines GitHub Actions: build/test (Maven + Angular), dockerizar api:latest e ia:latest.
- Deploy GCP (Cloud Run, Cloud SQL, Storage, Secret Manager) o Railway/Render.
- Variables: DB_URL, DB_USER, DB_PASS, JWT_SECRET, JWT_EXP_MINUTES, IA_BASE_URL, IA_API_KEY, STORAGE_BUCKET_URL.
